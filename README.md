## Featured Projects

### [s4-to-mamba](https://github.com/vaibhav3000/s4-to-mamba) `deep ML`

First-principles PyTorch implementations of S4D, Mamba, Mamba-2 and Mamba-3, with equivalence tests that verify the parallel and recurrent forms against each other, plus 1K-32K sequence-length benchmarks.

> Complex-valued transitions solve parity tracking at **98.3%** while real-transition SSMs and Transformers stay at chance. S4D collapses to **6%** on selective copying; selective SSMs hit **67%**.

### [aire](https://github.com/vaibhav3000/aire) `applied AI`

Trace-based evaluation engine for LLM and RAG systems: run the system once, store validated traces, then measure, compare versions and catch regressions forever on stored data.

> Caught a deliberate "fluent but uncited" regression: groundedness **0.57 to 0.00**, ungrounded failures +22. A live Gemini run on the same suite fixed abstention (**0 to 1.0**) at 15 s per case: the evaluator prices the whole trade-off, not one number.

### [repo-engineer](https://github.com/vaibhav3000/repo-engineer) `agentic AI`

A verified tool-using coding agent: a deterministic state machine wraps the planner (scripted recipes or a live Gemini LLM), every action passes schema validation, a workspace path jail and permission policies, and completion requires a green test suite.

> **4/4** tasks on the deterministic benchmark with zero failed tool calls; **2/2** with a live Gemini planner on the same validated runtime. The model proposes; the runtime disposes.
